# 精致化与高级动效设计（2026-09-27）

参考「COASTAL ARCADE / 01」风格指南截图，本轮目标：把 UI 做得更有高级动感，把 3D 建模做得更精致。

## 1. 车辆建模重做

### 做法

用侧剖面 `THREE.ExtrudeGeometry` 取代圆角盒子拼接。剖面点定义在 (x = 车身长度, y = 高度) 平面，沿宽度挤出后 `rotateY(-PI/2)` 把长度映射到世界 +Z（车头朝前），再 `translate(width/2, 0, 0)` 居中。

车身剖面（13 个点）：

```
后保险杠 (-2.34,0.30) → 后围 (-2.38,0.46) → 尾翼根 (-2.14,0.58)
→ 后翼子板峰 (-1.60,0.66) → 后腰线 (-0.90,0.63) → 风挡根部 (0.10,0.66)
→ 机盖凹陷 (0.78,0.60) → 机盖 (1.48,0.55) → 车头斜面 (2.06,0.40)
→ 车头尖 (2.36,0.30) → 前唇 (2.30,0.17) → 底板 (1.55,0.15) → (-1.62,0.15)
```

座舱单独一层挤出（宽 1.40，深色隔热玻璃），底边压在车身腰线上。

### 关键比例

| 尺寸 | 值 | 说明 |
| --- | --- | --- |
| 车长 | 4.74 | z ∈ [-2.38, 2.36] |
| 车宽 | 1.78 | 车身挤出深度 |
| 车高 | 1.15 | 座舱顶 1.09 + 车顶条 |
| 轴距 | 2.90 | 前轮 z=1.44，后轮 z=-1.46 |
| 前悬 / 后悬 | 0.92 / 0.92 | 对称，符合中置跑车 |
| 轮胎半径 | 0.36 | 第一版 0.54 过大，已下调 |
| 轮距 | ±0.93 / ±1.04 | 后轮比前轮宽 0.11 |

### 细节清单

前分流板 + 两侧导流小翼 / 侧裙 / 侧进气口 / 侧腰线 / 发动机盖散热口 / 贯穿尾灯带 + 两侧灯块 / 尾翼（支柱 + 主板 + 端板）/ 后扩散器 + 5 片竖向导流片 / 尾甲板百叶 / 车顶条 / 后视镜 + 支臂 / 六辐轮毂 + 刹车盘 + 中心盖 / 双出排气火焰 / 玩家橙色三角旗。

轮毂几何在 `tireGeometry.rotateZ(PI/2)` 阶段把轴向烘焙进顶点，因此 `wheel.rotation.x = spin` 才是绕轮轴自转，而不是原来的近似旋转。

## 2. 场景精致化

### `buildCoastalDetail()`

- **起点门架**：两根 9.2 高的锥形柱 + 25.6 横梁 + `START / FINISH` 广告牌（`createBillboardTexture` 画布贴图，正反两面）+ 6 颗呼吸跑马灯。
- **路边旗帜**：26 面，`PlaneGeometry(2.3, 1.15, 6, 1)` 挂在枢轴组上，`updateWorld` 里按 `sin(t*1.9 + phase)` 改变偏航与 `scale.x`，模拟被海风吹动。
- **海滩遮阳伞**：30 组。用新增的 `islandRadiusAt(angle)` 对 `islandOutline` 做 2D 射线求交，得到该方位角的海岸半径，再落在 0.965–1.016 倍之间（正好是沙滩环 0.98–1.04），并保证离赛道 > 34 才放置。
- **帆船**：7 艘，椭球船体 + 船舱 + 桅杆 + 主帆/前帆三角面，随浪起伏与横摇。
- **港口吊车**：5 座，塔架 + 5 道桁架 + 吊臂（缓慢摆动）+ 配重 + 司机室。
- **海鸥**：9 只，自定义 `BufferGeometry` 折线（两段三角翼），绕圈飞行并扇翅。
- **远景**：第二排远山（`MeshBasicMaterial` 带雾）、远岛、地平线太阳光晕与太阳本体。

### `buildRoadsideDetail()`

- **灌木**：190 丛，`IcosahedronGeometry(1, 1)` 5 色，按 3 环 + 抖动散布，5 个 `InstancedMesh`。
- **阔叶树**：34 棵，干 + 伞盖同样用 `InstancedMesh`。
- **路灯**：18 根，柱 + 底座 + 悬臂 + 发光灯头 + 灯罩，共用一份材质做整体呼吸。
- **弯道人字板**：按赛道曲率（`samples[i].tangent` 与 14 帧后切向的叉积）取最弯的 6 个点，每个点外侧摆 7 块警示板。
- **广告牌**：6 块，8.7×3.9 画布贴图 + 深色外框 + 双立柱。

### 跳台重做

原来是一块占满整条路、2.8 高的橙色楔形，从高处看非常突兀。改为：宽度收到 `ROAD_HALF_WIDTH * 0.92`、长度 13、高 2.15，深色甲板 + 黄色条纹 + 两侧墙（带加强筋）+ 顶端横梁。跳跃判定只依赖赛道参数 `t ∈ (0.565, 0.665)`，所以纯视觉改动不影响玩法。

### 海面与天空

`envMapIntensity` 从默认 1 降到 0.35、`roughness` 0.2 → 0.46，抵消掠射角把天空整片反射成白色的效果；主色改为 `hsl(0.528, 0.68, 0.33)`；浪线不透明度 0.22 → 0.38。天空三段色改为 `#0f7cba / #74cfdd / #f0c583`。

## 3. UI 高级动效

| 元素 | 动效 |
| --- | --- |
| 玻璃面板 | `panel-sheen` 7.5s 循环斜向扫光（`::after` + `z-index: 0`，子元素 `z-index: 1` 保证不遮挡） |
| 面板悬停 | 边框提亮 + 外发光 |
| 速度表 | `.hot`（车速 > 62%）切橙环、外发光、数字辉光 |
| 氮气条 | `.nitro-shine::after` 流光；满槽 `.ready` 黄色描边 + 数值闪烁 + 辉光 |
| Boost 提示 | `boost-spring` 弹簧入场（0.62 → 1.14 → 0.97 → 1），带模糊消散 |
| 倒计时 | `count-pop` 加入 16px 模糊与 1.7 倍起始缩放；kicker 与 caption 单独错峰 |
| 排名 | 玩家行 `row-breathe` 呼吸；名次变化时 `rank-up` / `rank-down` 绿/红闪动并横向位移 |
| 状态帧 | `#game-shell.boosting` 拉满速度线 + 暖橙底部渐晕 + 青/橙色差边缘；`.drifting` 加暖色边缘 |
| 主菜单 | 卡片整体 `menu-rise`，8 个子元素 `menu-fade` 逐条 70ms 错峰；主按钮常驻扫光 |
| 小地图 | 玩家 70 点渐隐轨迹（`updateMinimap` 里每移动 1.6 单位采样） |

`prefers-reduced-motion: reduce` 时统一关闭扫光与流光。

## 4. 文字重叠修复

- 主菜单期间给 `#hud` 加 `.hud-dim`，把左侧栏、标题、速度表、氮气条整体淡出上移 10px，彻底消除与大字标题的重叠。
- 430px 断点重排：标题 `21px` + `white-space: nowrap`（原来换行后撑高压住状态条），横屏提示下移到 88px，左侧栏下移到 126px，氮气组上移到 `bottom: 262px`，触控键位左右分居（右侧 `bottom: 112px`）。修复后 10 个 HUD 包围盒两两求交只剩 `center × boost`（boost 是 center 的子元素，属误报）。

## 5. 验证

- AI 固定步长 300 秒模拟：5 辆全部完赛 3 圈（176.7–188.3s），`aiStuckTimer` 峰值 4s（能自行恢复），`|lateral| > 9.4` 的护栏接触时间为 0。
- 渲染开销：约 85k 三角形、806 draw call、14 张程序化贴图；软件渲染器仍走降级路径。
- 单文件版：外部 script / stylesheet 均为 0，Chromium 可开始比赛并进入 `racing`，无页面与控制台错误。
