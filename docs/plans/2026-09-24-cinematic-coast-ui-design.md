# 晴空电影级海滨与竞速 HUD 升级设计

日期：2026-09-24  
状态：用户已确认 A 方案

## 目标

在不改变现有驾驶物理、漂移机制、AI 和比赛流程的前提下，把当前“明亮低多边形原型”提升为具有商业网页赛车 Demo 质感的晴空电影级视觉：更真实的材质与光照、更明确的空间层次、更有设计感的中文 HUD 字体系统。

## 视觉方向

- 美术基调：晴空电影级海滨公路，参考自然主义日光、空气透视和宽银幕赛车摄影；不做官方地图或 UI 复刻。
- 主色：深海蓝、晴空青、暖白；速度与危险使用珊瑚橙，漂移使用冰蓝，氮气使用金黄。
- 画面层次：远景山体/城市与雾 → 中景棕榈、灯塔、护栏 → 近景路面纹理、车辆、粒子。
- 3D 目标：程序化几何保持轻量，但材质使用粗糙度、金属度、透明度和发光差异；道路有磨损、标线、阴影和边缘层次；海面有缓慢高光变化；车辆有车身高光、玻璃反射和接触阴影。
- UI 目标：像一块有设计语言的赛车遥测玻璃，而不是普通网页卡片。中文标题、英文副标题、数字速度、状态标签使用明确不同的字体层级。

## 3D 实现

1. 调整渲染器：保留 ACES Filmic，但增加物理正确色彩、曝光和阴影质量；根据设备能力限制像素比和阴影。
2. 光照：降低过曝的纯色感，使用半球光 + 暖色方向光 + 冷色环境补光；让路面和车身产生可读的明暗面。
3. 地面与海面：增加海岸线层次、沙滩/陆地区分、海面色相与高光变化；远景使用雾化淡出。
4. 道路：生成更细的沥青颗粒、磨损条纹、中心虚线和边缘反光条；降低纯黑感，保留夜间可读的深蓝路面。
5. 车辆：调整车漆金属度、玻璃透明度、刹车灯和尾焰层次；近景镜头能看到车顶、车尾和前轮。
6. 空间物件：棕榈树、灯塔、云层和护栏增加尺寸/颜色变化；重复物件维持实例化性能。
7. 镜头：追尾镜头略微降低并拉近，动态 FOV 只在高 boost 时明显扩张；加入轻微的镜头阻尼和速度雾化，不牺牲赛道可读性。

## UI 实现

- 中文标题使用本地可用的“优设标题黑/站酷酷黑/微软雅黑”回退链；英文副标题使用 Bahnschrift/Arial Narrow；数字使用 `font-variant-numeric: tabular-nums` 和等宽数字栈。
- 品牌标题使用斜切、错位阴影和一条珊瑚橙速度线；赛道名使用更宽的字距和小型编号。
- HUD 面板减少圆角和边框噪声，增加细网格、刻度线、半透明渐变和局部高光；速度表成为右下角主焦点。
- 漂移/普通喷/双喷/断位喷使用独立的短促动效和颜色，不长期遮挡赛道。
- 中文正文最小 14px，按钮具备 hover/active/focus-visible 状态，窄屏保持触控可用。
- 数字、时间和名次采用稳定的等宽数字，避免高速更新时跳动。

## 性能与降级

- 不加载外部模型、贴图或字体文件；纹理全部由 Canvas 程序化生成。
- 重复景物和粒子继续使用 InstancedMesh / Points；新增效果以材质、光照和 CSS 为主。
- 低性能设备降低阴影、粒子数量和海面波纹更新频率；核心物理与可读性不降级。
- 保持现有 WebGL 错误页、暂停、失焦清空输入和本地静态部署能力。

## 验收

- `node --check src/main.js` 与 `npm.cmd run build` 通过。
- 本地静态服务器返回 200，Playwright 无控制台错误。
- 截图检查：车辆在镜头中、道路和海面有层次、棕榈/护栏可见、无粒子方块、HUD 不遮挡前方赛道。
- 键盘开始、加速、漂移、普通喷、双喷、断位、氮气和镜头切换仍可用。
